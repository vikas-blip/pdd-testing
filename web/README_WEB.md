# ThermaScan Web Application Section (`/web`)

This directory contains all **Web Application** frontend & backend server code files:

## 📁 Directory Files
- 📄 index.html — Web UI HTML layout, dashboard grid, AI Care modal, 24/7 Pharmacy search modal, First Aid guide.
- 📜 app.js — Web JavaScript logic, ThermaScan Clinical AI Engine v1.0, Firebase Cloud sync, Nominatim/Overpass Pharmacy geocoding.
- 🎨 style.css — Styling system, glassmorphism theme, dark mode, responsive CSS.
- ⚙️ server.js — Node.js HTTP server configured for port 8080 (http://localhost:8080/).
- 📦 package.json — Node.js project manifest & start scripts (npm start).
